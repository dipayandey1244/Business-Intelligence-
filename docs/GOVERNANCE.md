# Governance and responsible use

- **Synthetic-only:** every record and outcome is generated by the application; no real client data is needed.
- **Human ownership:** the review queue is a prompt for investigation, never an instruction to contact or treat a client.
- **Prediction vs causality:** adoption propensity estimates synthetic event likelihood. It is not incremental campaign impact.
- **Wallet proxy:** the wallet-gap field is simulated and must not be described as observed wallet share.
- **AI boundary:** optional LLM output is an unverified draft. Validate numbers and assumptions before reuse.
- **Production gaps:** require approved data access, purpose limitation, access controls, security review, privacy and fair-treatment review, independent validation, monitoring, documented sign-off and incident handling.
