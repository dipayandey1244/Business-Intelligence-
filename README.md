# Business Intelligence — CIB Client Intelligence Lab

An independent portfolio project demonstrating synthetic corporate & institutional banking analytics, governed recommendations, and optional AI-assisted analysis.

**Not affiliated with HSBC.** All data and results are synthetic; no confidential or real client data is used.

See the project documentation for setup and deployment. The Streamlit app is the main entry point (`app.py`). Never commit API keys; configure `GROQ_API_KEY` in the hosting platform's secrets.
